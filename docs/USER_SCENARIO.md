# 사용자 시나리오 (User Scenarios)

## 1. 방문자 (Visitor) 시나리오
- **방문자**: 마이링크 페이지를 통해 정보를 얻고 외부 사이트로 이동하는 사용자.

| 상황 | 사용자 시나리오 |
| :--- | :--- |
| **페이지 접속** | 사용자는 특정 사용자의 마이링크 URL을 입력하여 해당 프로필 페이지를 확인한다. |
| **정보 확인** | 사용자는 소유자의 닉네임과 소개글(Bio)을 읽고 어떤 정보를 공유하는지 파악한다. |
| **링크 이동** | 사용자는 관심 있는 링크를 클릭하여 해당 외부 사이트로 이동한다. (새 탭에서 오픈) |

---

## 2. 소유자 (Owner) 시나리오
- **소유자**: 자신의 프로필과 링크를 관리하는 사용자.

### 2.1 프로필 관리
| 상황 | 사용자 시나리오 |
| :--- | :--- |
| **로그인/접속** | 소유자는 구글 계정으로 로그인하여 즉시 대시보드(관리 화면)로 진입한다. |
| **닉네임 수정** | 소유자는 프로필 영역의 편집 아이콘을 클릭하여 닉네임을 수정하고 저장한다. |
| **소개글 수정** | 소유자는 소개글 영역의 편집 아이콘을 클릭하여 내용을 변경한다. |

### 2.2 링크 관리
| 상황 | 사용자 시나리오 |
| :--- | :--- |
| **링크 추가** | 소유자는 '링크 추가' 버튼을 눌러 새 링크의 제목과 URL을 입력한다. |
| **링크 정보 수정** | 소유자는 링크 아이템에 있는 편집 아이콘을 클릭하여 제목이나 URL을 수정한다. |
| **링크 삭제** | 소유자는 링크 아이템의 삭제 버튼을 클릭하여 불필요한 링크를 제거한다. |

---

## 💡 개선 제안
- **공유 기능**: 소유자가 자신의 마이링크 URL을 쉽게 복사할 수 있도록, 대시보드 상단에 'URL 복사' 버튼을 제공하는 것을 제안합니다.
- **실시간 미리보기**: 관리 화면 옆에 방문자가 보게 될 공공 프로필 페이지를 실시간으로 미리볼 수 있는 뷰어를 배치하면 사용자 경험이 크게 개선될 것입니다.

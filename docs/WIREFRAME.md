# 와이어프레임 (Wireframes)

## 1. 대시보드 (관리자 화면)
- **레이아웃**: 2단 구성 (좌측: 관리 영역, 우측: 실시간 미리보기)

### 1.1 관리 영역
- **상단**: 
    - 서비스 로고
    - "URL 복사" 버튼
    - 프로필 아이콘 (로그아웃 버튼)
- **프로필 설정**:
    - `[닉네임]` (편집 아이콘)
    - `[소개글(Bio)]` (편집 아이콘)
- **링크 관리**:
    - [링크 추가 버튼]
    - 링크 목록 (Card 컴포넌트)
        - `[파비콘]` + `[제목]` (편집 아이콘)
        - `[URL]` (편집 아이콘)
        - `[삭제 버튼]`

### 1.2 미리보기 영역 (우측 뷰어)
- 현재 수정 중인 내용을 공공 프로필 페이지와 동일한 UI로 실시간 반영.

---

## 2. 공공 프로필 페이지
- **레이아웃**: 중앙 정렬형 미니멀 레이아웃 (모바일 퍼스트)

- **상단 프로필 영역**:
    - **닉네임**: 폰트 크기 대(Large)
    - **소개글(Bio)**: 닉네임 하단 배치
- **링크 리스트 영역**:
    - 링크 버튼 (shadcn/ui Button 컴포넌트 스타일)
    - 좌측에 해당 도메인의 파비콘 표시
    - 우측에 텍스트 중앙 정렬
- **하단**:
    - '마이링크 만들기' (간단한 브랜딩 링크)
